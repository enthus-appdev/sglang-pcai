# sglang-pcai

Pinned [SGLang](https://github.com/sgl-project/sglang) serving images for **HPE Private Cloud AI (PCAI)**.

This repository provides an arguments-only server entrypoint and automated GHCR publishing, following the conventions of [vllm-pcai](https://github.com/enthus-appdev/vllm-pcai). It does not deploy a model service.
